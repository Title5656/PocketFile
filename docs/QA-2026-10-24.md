## Evidence and method

- Baseline: 42 unit/component tests; typecheck/build passed.
- Final local verification: clean `npm ci`, **52 unit/component tests**, typecheck and production build passed; **15 Chromium E2E tests passed**. `npm audit` reported **0 vulnerabilities** with this lockfile on 2026-10-24. The PWA precache is about 3.86 MB versus about 10.65 MB at baseline; no OCR runtime or public source maps remain in `dist/`.
- Regression evidence: catalog/removal, incorrect rotated-signature origin, invalid physical size and unsafe output filename tests first failed on the baseline. Numeric/budget/format checks were added and exercised. An independent review found an upload-validation/busy race; its regression test failed before the fix and then passed.
- Unit/component coverage includes selection decode resolving after reset/new selection, ZIP double click/failure, cancel locks, numeric validation, input byte/pixel budgets, PDF transforms and preferences.
- Chromium E2E generates real PNG/PDF inputs, selects files through actual file inputs, processes, downloads and independently reopens PNG (`pngjs`), JPEG (`jpeg-js`), ZIP (`jszip`) and PDF (`pdf-lib`). It verifies physical-size pixels and PNG DPI metadata. Corrupt/mislabelled input is exercised in every remaining tool.
- Signature E2E uses real pointer capture/movement, keyboard adjustment and screenshot pixel bounds to compare editor ink against rendered output at 0/90/180/270 degrees with nonzero CropBox offsets. A PDF.js preview alone is not treated as proof of exported placement.
- Keyboard modal focus/restore, browser Back/Forward including canceled navigation, 320px overflow, asset paths and service-worker offline conversion are exercised. Slow-operation tests cover cancellation and export locking.
- E2E initially failed because sandboxed browser downloads were canceled and its temporary browser cache changed between commands; these were infrastructure failures, resolved using an accessible browser cache and an appropriately permitted test run. Some exact label selectors included option text; role-based combobox selectors fixed the tests without changing product behavior.

## Review decisions

An independent reviewer traced the changed code and reported two introduced P2 issues: upload validation could leave the picker disabled after a busy transition, and canceled Back rewrote the dashboard history entry. Both were addressed and covered by regression/browser checks. No additional introduced correctness issue was confirmed by that review.

Deferred maintenance is intentional for the personal GitHub Pages scope: giant-module restructuring, complete lint/SBOM/license tooling, virtualization for 500 pages, typed signature authoring, exhaustive device certification and further PDF/HEIC bundle optimization. Existing artwork was not changed. Rollback is a revert of the remediation commits followed by the existing main-branch Pages workflow.
